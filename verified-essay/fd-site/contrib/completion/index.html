This folder holds shell-completion files so that fd 's command-line options autocomplete in your terminal.

How completions work

Each shell needs its own completion recipe. The Zsh file (_fd) defines the full argument grammar: it knows about every flag, type filter, and size limit. It even hides rare options unless you type their prefix to keep suggestions tidy.The Bash and Fish completions are thin wrappers that reuse the Zsh logic or the upstream fd completions.

Seams and sharp edges

Single source of truth

The Zsh completion is the only authoritative source; the other shells simply delegate to it.

Forgotten flag

If you add a new flag without updating the Zsh completions, the prompt will never suggest it.

Scope

Inside the Zsh file

The file defines argument groups for hidden files, ignore rules, case sensitivity, regex vs. glob, depth, pruning, and execution. It uses is-at-least to stay compatible with Zsh 5.2 and strips unsupported groups automatically on older shells.
