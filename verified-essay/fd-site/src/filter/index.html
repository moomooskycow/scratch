Filtering files by owner, size, and time

The filter directory holds the logic that lets you narrow down file searches by owner, size, or last-modified time. Each filter is a small, focused module with a public type and a handful of functions.

How filters work

The mod.rs file re-exports the three public filter types: SizeFilter, TimeFilter, and (on Unix only) OwnerFilter.

Each filter parses a user-supplied string into an internal representation, then exposes a method to check a file metadata value. For example, SizeFilter::from_string accepts strings like +1M or -500k and returns a Min, Max, or Equals variant.

Seams and sharp edges

What can hurt you

If you add a new unit or change the parsing regex in SizeFilter, you must update the exhaustive test table that covers every SI and binary prefix. Missing a prefix or mis-scaling a multiplier will silently produce wrong sizes.

Always defined

All filters return Option or Result; a malformed input string will never crash. The caller must propagate None or Err correctly.

Resource boundary

OwnerFilter compares user and group IDs; it resolves names to IDs at parse time, so the user or group must exist on the current system.
